# Commercial Performance Dashboard

An interactive Excel dashboard analyzing global sales, profitability, shipping costs, and regional metrics across product categories.

![Dashboard Preview](dashboard_preview.png)

## Overview
This project evaluates commercial sales performance across categories, sub-categories, and regions. It features dynamic KPI metrics linked with interactive slicers to track revenue, shipping overhead, and profit margins.

## Key Features
* **Interactive KPI Cards:** Real-time summary of Total Sales, Profit, Profit Margin, and Shipping Costs.
* **Dynamic Slicers:** Filter dataset by Category (`Office Supplies`, `Furniture`, `Technology`), Country, Quarter, and Sub-Category.
* **Regional & Product Analytics:** Visual Breakdown of Sales vs. Discounts per Region, Contribution of Categories to Sales, and Quarterly Sales Trends.

## Project Structure
* `Commercial_Performance_Dashboard.xlsx` - Interactive Excel workbook containing pivot tables, charts, and raw datasets.
* `dashboard_preview.png` - Screenshot preview of the interactive interface.

## How to View
1. Clone or download the `.xlsx` file from this repository.
2. Open in **Microsoft Excel** to interact with slicers, filters, and pivot tables.
